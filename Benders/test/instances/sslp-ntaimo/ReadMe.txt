These randomly generated stochstic server location problem (SSLP) instances are named 
SSLP_m_n_si where.
m = number of potential server locations
n = number of potential clients
s = number of scenarios
i = a,b,c,d,e; represents the replication for the instance (same size but different scenarios (outcomes))

Please see Ntaimo and Sen (2005) for model description and how the instances were generated.
